# Calque changelog

## Android 1.11
- Open in another app, Share, Save to Files and Print from the ⋮ menu

## iPad 1.1
- Measure panel opens at full width
- Smoother panning
- Sheet edges can be brought under the cross while measuring
- Hairlines (via PDFium), from the ⋮ menu or Settings
- Keyboard now appears for custom scale and calibration

## iPad 1.2
- Open in another app, Share, Save to Files and Print from the ⋮ menu
- Scale confirmation after calibration

## Android 1.12
- DXF opening (to scale), DWG hint
- Export with markup
- Text search

## Android 1.13
- DWG opening via LibreDWG; Android app is now GPL-3.0 open source (android/)
- Fix: stray diagonal line when zooming into DXF drawings

## Android 1.14
- DWG/DXF layouts as pages (viewports, scales, frozen layers), layout names as sheet titles
- New icon

## Android 1.15
- DWG colours, hatch order, speed, extents and layout-name fixes

## iPad 1.3
- DWG/DXF with layouts, export with markup, text search, multiple windows (Split View), new icon; GPL-3.0
